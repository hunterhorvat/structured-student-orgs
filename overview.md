# **Understand the file-organization system**

## **Why the system is necessary** 

A file name functions as a compact technical description. It should give collaborators enough information to recognize a file without opening it. A folder system provides a second level of description by grouping files according to their role in the research process. 

| Problem | Design Response |
| ------- | --------------- |
| Members cannot identify a file's contents | Every name includes a controlled document type code |
| Files appear in an unpredictable order | Every name begins with the date |
